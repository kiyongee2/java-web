** AWS EC2(Elastic Compute Cloud) 생성하기 **
1. 계정 만들기 
- 이메일 주소, 계정이름 :  이메일 인증(인증문자)
- 인증후 비밀번호 입력
- 회원 가입 진행후(영어로 작성)
- 해외 결제가 가능한 카드 입력(100원 결재후 환불됨)

2. aws 프리티어
  - 기본 지원 무료 - ec2 750시간 무료, 200달러 크레딧

3. ec2 생성
  - 인스턴스 시작
  - 서버 이름(web_server)
  - ubuntu(t2.micro)
  - 키페어 이름: my-ec2-key.pem
  - 인스턴스 실행
  - 보안 그룹: TCP 3000 포트 열기
  - 퍼블릭 도메인 : 브라우저 접속

*** net-tools 설치 : 네트워크 상태 표시
sudo apt install net-tools
netstat -nltp  

*** node 설치
sudo apt install npm
npm -v, node -v 확인

*** github 연결(git 없으면 설치)
sudo apt install git
git clone 리엑트 프로젝트 리포지터리
npm run build
npm install -g serve
serve -s build
접속 오류
*** nginx 설치
sudo systemctl start nginx -> 시작
sudo systemctl enable nginx
sudo rm -rf /var/www/html/*  -> 기존 html 삭제
sudo cp -r build/* /var/www/html/ ->빌드 파일 복사
sudo systemctl restart nginx -> 재시작

sudo systemctl status nginx -> 상태
sudo systemctl stop nginx -> 중지

** 보안 그룹 규칙 추가
80 - HTTP
22- SSH

** 브라우저 접속
http:<퍼블릭IP>
