** AWS EC2(Elastic Compute Cloud) 생성하기 **
1. 계정 만들기 
- 이메일 주소, 계정이름 :  이메일 인증(인증문자)
- 인증후 비밀번호 입력
- 회원 가입 진행후(영어로 작성)
- 해외 결제가 가능한 카드 입력(100원 결재후 환불됨)

2. aws 프리티어
  - 기본 지원 무료 - ec2 750시간 무료, 200달러 크레딧

3. ec2 생성
  - 인스턴스 시작
  - 서버 이름(web_server)
  - ubuntu(t2.micro)
  - 키페어 이름: my-ec2-key.pem
  - 인스턴스 실행
  - 보안 그룹: TCP 80, 8080-> 2개 포트 열기
  - 퍼블릭 도메인 : 브라우저 접속

*** net-tools 설치 : 네트워크 상태 표시
sudo apt install net-tools
netstat -nltp 

*** jdk21 설치 및 jar 파일 배포
$ sudo apt update
$ apt-cache search openjdk (검색)
$ apt-cache search openjdk | grep openjdk-21(상세 검색)
$ sudo apt install openjdk-21-jdk (설치)
$ java -version(설치 확인)

** jar 파일 업로드 명령
pem  파일 권한 수정
icacls "D:\aws-ec2\my-ec2-key.pem" /inheritance:r
icacls "D:\aws-ec2\my-ec2-key.pem" /grant:r "%USERNAME%:R"
권한 확인
icacls "D:\aws-ec2\my-ec2-key.pem"

scp -i [키파일.pem] [업로드할_파일명] [EC2_계정명]@[EC2_IP]:[저장할_경로]
예) D:/aws-ec2 폴더안에 pem과 jar파일 준비, EC2 퍼블릭 IP - 52.62.171.176
D:\aws-ec2>scp -i "my-ec2-key.pem" "test_app.jar" ubuntu@52.62.171.176:/home/ubuntu/

$ ls - 파일 확인
$ java -jar test_app.jar (배포)
$ nohup java -jar test_app.jar & (nuhup - SSH 종료되어도 계속 실행됨)
브라우저 접속 - http://52.62.171.176:8080
** 프로세스 중지 방법
1. kill -9 PID
2. pkill -f test_app.jar
